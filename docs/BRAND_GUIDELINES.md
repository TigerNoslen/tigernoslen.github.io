# Tiger Nation HQ Brand Guidelines

## 1. Brand Identity

### Primary Name

Tiger Noslen Gaming

### Community Name

Tiger Nation

### Website Identity

Tiger Nation HQ

### Creator Code

TIGERNOSLEN

Use with:

#EpicPartner

### Brand Personality

Tiger Nation HQ should feel:

- Energetic
- Welcoming
- Family-friendly
- Modern
- Gaming-focused
- Confident
- Fun without appearing childish
- Professional without feeling corporate

---

## 2. Core Design Principle

The website should feel like entering the digital headquarters of Tiger Nation.

It should not feel like:

- A generic link page
- A corporate business website
- A cluttered gaming forum
- A copy of Fortnite's interface
- An advertisement-filled creator page

Every section should have a clear purpose and guide the visitor toward a useful action.

---

## 3. Primary Audience

The website is designed primarily for:

- Existing Tiger Nation viewers
- New viewers discovering Tiger Noslen Gaming
- Fortnite players
- YouTube and TikTok viewers
- Mobile users scanning the TNG QR code
- A family-friendly audience that includes children and teenagers

The design must remain clear, safe, welcoming and easy to use.

---

## 4. Colour Palette

### Primary Background

`#0D0F12`

Use for the main page background.

### Secondary Background

`#171A1F`

Use for cards, panels and navigation surfaces.

### Elevated Surface

`#21252C`

Use sparingly for highlighted panels or interactive cards.

### Primary Orange

`#FF7A00`

Use for:

- Primary buttons
- Important headings
- Active navigation items
- Highlights
- Creator Code accents
- Small glowing details

### Bright Orange

`#FFA033`

Use for:

- Hover states
- Focus states
- Selected items
- Subtle lighting effects

### Dark Orange

`#C95600`

Use for:

- Button shadows
- Borders
- Darker accent details

### Primary Text

`#FFFFFF`

Use for headings and important information.

### Secondary Text

`#B8BDC7`

Use for descriptions and supporting information.

### Muted Text

`#7F8794`

Use for captions, timestamps and less important text.

### Success Green

`#36D17C`

Use only for positive statuses such as:

- Live systems working
- Successful actions
- Available features

### Live Red

`#FF3B3B`

Use only for:

- LIVE indicators
- Urgent stream-related notices

---

## 5. Colour Usage Rules

- Dark colours should dominate the website.
- Orange is an accent and should not cover large portions of the page.
- White should be reserved for important readable text.
- Bright orange should primarily appear during interaction.
- Red should only represent live or urgent information.
- Avoid using many unrelated colours in the same section.
- Social-platform colours may appear inside their respective icons or buttons, but the overall button design should remain consistent with TNG branding.

---
